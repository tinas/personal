# About me

Hi, I'm Ahmet, a full-stack developer from Türkiye.

By day I'm a Senior Frontend Engineer at [MobileAction](https://www.mobileaction.co). I write a lot of TypeScript there, mostly Vue and React. I've done my share of backend work with Node.js over the years, but these days I live almost entirely on the frontend. The parts of the job I enjoy most are the quiet ones: figuring out where state should live, and leaving code a little easier to reason about than I found it.

## Things I'm building

The project closest to my heart right now is [usewagen](https://usewagen.dev). It keeps reactive state in the URL and in browser storage, with real types instead of raw strings, so a page number comes back as a number and a date comes back as a date. It sticks to one rule: the source stays in charge, so whatever you write is exactly what you read back.

usewagen started life as [qpick](https://github.com/tinas/qpick), which solved the same problem for the URL alone. Then I caught myself writing the same sync logic all over again for `localStorage`, and one model started to make a lot more sense than two.

I also look after a few smaller libraries, each one born from a problem I hit in a real product:

- [drawerly](https://drawerly.dev), a framework-agnostic way to build stacked drawer interfaces
- [qubo](https://github.com/tinas/qubo), a MongoDB-style query builder for plain JavaScript objects
- [fakend](https://github.com/tinas/fakend), a promise-based mock adapter for axios

And when the projects I depend on need a hand, I try to show up with a good issue or a small fix.

## Why I write

Mostly so I don't forget. Why something ended up the way it did, what I got wrong before I got it right, the little things I'll want again in six months. I keep those [notes](/writing/) in the open, and if one of them helps you too, that honestly makes my day.
