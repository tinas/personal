# About Me

👋 I'm Ahmet, a frontend developer from Turkey.

🛠️ I work at [MobileAction](https://www.mobileaction.co) as a Senior Frontend Developer. Most of my work is in TypeScript: Vue and React on the frontend, and Node.js services with Express when a feature reaches that far. A lot of my time goes into state, API design, and trying to make code simpler to reason about.

🚃 The library I care most about right now is [usewagen](https://usewagen.dev). It keeps reactive state in the URL and in browser storage with real types instead of raw strings, so a page number comes back as a number and a date comes back as a date. It follows one rule: the source stays in charge, so whatever you write is exactly what you read back. usewagen grew out of [qpick](https://github.com/tinas/qpick), which solved the same problem for the URL alone. Once I caught myself rewriting the same sync logic for `localStorage`, one model made more sense than two.

📦 I maintain a few other libraries as well: [drawerly](https://drawerly.dev), a framework-agnostic system for building stacked drawer interfaces; [qubo](https://github.com/tinas/qubo), a MongoDB-style query builder for plain JavaScript objects; and [fakend](https://github.com/tinas/fakend), a promise-based mock adapter for axios. Each of them started as a problem I hit in a real product. I also try to give back to the projects I depend on, with issues and small fixes where I can.

📝 I keep my notes in the open on the [writing](/writing/) page: why something ended up the way it did, what I got wrong before I got it right, and small things I don't want to forget. If one of them happens to help you too, even better.

🤝 I'm on [GitHub](https://github.com/tinas), [X](https://x.com/tinasdev) and [Bluesky](https://bsky.app/profile/tinasdev.bsky.social). Always happy to talk about Vue, API design, or something you're stuck on.
